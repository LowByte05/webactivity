06A learning path

A suggested route from first idea to first launch.

  1. Start with curiosity

    Find something worth making

    Pick a small idea from your everyday life. Sketch what the page should do before writing code.

  2. Learn by doing

    Build one piece at a time

    Start with the content, give it a style, then add one useful interaction.

  3. Put it out there

    Share, listen, improve

    Check it on your phone, ask a friend to try it, and publish when you're ready.
